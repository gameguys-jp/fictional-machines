# Fictional Machines

現実には存在しない機械を、工学的な設計とフィクションの両面から構築し、実際に動作する形で実現するための基本構想と分類体系です。

- [Fictional_Machines.md](Fictional_Machines.md)：基本構想・設計原則・分類体系（F／T／D／L／E／M／S／V／N）と、個別プロジェクトの共通記述フォーマット。版は文書の冒頭に記載（作業中の版で、随時更新します）。
